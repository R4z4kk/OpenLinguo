# OpenLinguo

Open-source language-learning app. Mandarin first, English next, more languages later.

OpenLinguo combines frequency-based prioritization, spaced repetition (FSRS), character decomposition, tone training with pitch visualization, handwriting and pinyin typing, AI-assisted writing practice (bring your own key) and graded reading. It is local-first: you can learn offline, without an account.
